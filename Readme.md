# Jadoo - Travel Agency Landing Page

A modern, responsive travel agency landing page built with HTML, CSS, and Vanilla JavaScript. Features dynamic interactive components, dark mode toggle, destination carousel, testimonials stack, user authentication drafts persistence, and mobile-friendly drawer navigation.

## Features

- **Hero & Services Showcase**: Interactive presentation of travel categories and destinations.
- **Dynamic Destination Carousel**: Touch-enabled, auto-playing slider with progress bar indicators.
- **3D Testimonials Stack**: Layered interactive testimonial cards with vertical/touch controls.
- **Dark Mode Support**: Persistent dark/light theme switching with multi-tab synchronization and system preference fallback.
- **Authentication & Persistence**: Sign-up / Sign-in with session management, live draft saving, and multi-layer storage (LocalStorage + Cookie backup).
- **Responsive Layout**: Tailored for desktop, tablet, and mobile screens.

## Project Structure

```
├── assets/         # Images, icons, and illustrations
├── components/     # Sign-in & Sign-up authentication page
├── styles/         # Stylesheets (styles, dark-theme, tablet, mobile, auth)
├── script.js       # Core interactivity, storage, themes, and carousels
└── index.html      # Main landing page
```

## Getting Started

Open `index.html` in any modern web browser or run with a local live server.
